# 逐步执行清单

本文是公开仓库中的通用执行合同，不是本机实时状态。当前状态、证据和阻塞项写入被忽略的本地台账 private/execution-ledger.local.md；该台账以及真实清单、事务证据、会话记录不得进入 Git。每批只推进一个可验证步骤，先备份、再小范围修改、再测试、再记录，避免凭记忆跳项。

> 勾选仅表示对应公开框架合同已交付；本机实时状态与证据不写入本仓库。

## 执行纪律

1. 一步一验收：每个 P 编号必须有完成条件、验证输出和下一步；未完成不标完成。
2. 公开/私有分流：公开仓库只放规范、schema、代码、合成夹具；本地路径、用户名、清单、日志、证据、凭据和会话只在宿主许可的本地受限区保存。
3. 可逆优先：已有文件用小范围补丁；写操作先 dry-run、备份、哈希、冲突检查；失败保守标记，必要时停止并回滚。
4. 不越界：不跟随重解析点、不跨未授权根、不直接改全机共享索引、不读取或输出凭据、不启用 Computer Use 除非当前任务明确要求。
5. 验证闭环：npm test、npm pack --dry-run、git status --short、发布包白名单和公开边界扫描在收口前复核。

- [x] P1-2 快速检索：为元数据清单建立可重建的倒排/FTS 或等价二级索引，查询不再每次线性扫全量 gzip JSONL；定义合成基准与 p95 测量脚本；旧清单仍可降级使用但必须标 stale。（框架合同检查点；本机实时状态见本地台账）
- [x] P1-3 重复簇与内容指纹：只读取授权范围内的文件流，按算法/摘要/字节数聚合候选簇；显式区分权威、备份、生成物、版本化输出；不得据哈希自动删除或降级。（框架合同检查点；本机实时状态见本地台账）
- [x] P1-4 增量刷新：按快照差异生成新增/变更/删除候选，保留 tombstone，原子切换索引指针，失败回退旧指针并记录跳过项；不把快照当实时文件系统。（框架合同检查点；本机实时状态见本地台账）
- [x] P1-5 分类建议：基于名称、目录上下文、元数据、版本控制状态生成建议和置信度；默认只输出 dry-run，不自动移动；unknown 与 hold 保留。（框架合同检查点；本机实时状态见本地台账）

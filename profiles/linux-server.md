# Linux Server Profile

本文件为服务器治理指导，不是生产执行器，也不授予 SSH、sudo、云平台或服务管理权限。开始前必须有明确的目标主机、账户范围、维护窗口（如适用）、可读/可写路径和允许的副作用。

## 身份与只读发现

- 远程访问前验证主机身份与 pinning 的 host key；认证凭据由本机适配器提供，不读取、不回显、不写入模型上下文。
- 首轮只读检查挂载点、文件系统、容量/inode、服务和包管理归属、容器/卷绑定及已授权目录的有限元数据。不要对根目录发起无界递归扫描。
- 默认不跟随 symlink、不跨越 mount boundary、不读取配置/日志正文；需读取时限定文件、目的、脱敏方式与保留期。
- 记录观察的时间、执行身份、命令/工具能力和覆盖范围；容量统计或缓存结果不能代替源端重新核验。

## Linux 常见目录角色提示

| 路径 | 常见责任 | 治理注意事项 |
| --- | --- | --- |
| `/etc` | 系统与服务配置 | 包管理/配置管理可能拥有；更改前备份、审阅差异并检查服务依赖 |
| `/var/lib` | 服务持久状态与数据库 | 高风险应用状态；禁止按“旧文件”清理 |
| `/var/log` | 系统/应用日志 | 保留与轮转由日志策略控制；不要用手工删除替代 logrotate 或服务策略 |
| `/home` | 用户数据与项目 | owner/权限/ACL/配额需保留；按项目和数据分类 |
| `/srv` | 对外服务数据 | 需确认服务引用、发布权限、备份及流量影响 |
| `/opt` | 可选软件/自建应用 | 识别部署工具、版本切换链接与回滚目录 |
| `/tmp`, `/var/tmp` | 临时数据 | 依据本机清理策略、所有者和活跃进程判断，不能只看年龄 |
| `/proc`, `/sys`, `/dev`, `/run` | 虚拟或运行时文件系统 | 不按普通持久目录盘点或归档 |

以上只是 Linux 常见约定；具体发行版、容器、软件和挂载布局可能不同。

## 服务器变更门槛

写入、权限/owner 修改、服务重启、挂载变更、包管理、数据库迁移及删除均是独立高影响操作，需要明确到目标和效果的授权、备份/恢复步骤及变更窗口。采用临时目录与原子替换时，先确认文件系统语义、权限、SELinux/AppArmor 标签、ACL、xattrs、硬链接和打开文件句柄不会被破坏。

若无法验证主机身份、所有权、备份可用性或服务影响，保持只读并将项目标记为 hold。不得把日志、配置、数据库转储或主机清单复制到公开仓库。
